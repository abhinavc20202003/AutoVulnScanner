# AutoVulnScanner

A web-based vulnerability scanning tool built using Flask.

## Features
- Nmap port scanning
- Subdomain enumeration
- Optional Nikto scan
- Severity classification (Low / Medium / High)
- Interactive charts (Chart.js)
- PDF report generation

## Tech Stack
- Python (Flask)
- Nmap
- Nikto
- HTML/CSS
- Chart.js

## Installation

```bash
git clone https://github.com/abhinavc20202003/AutoVulnScanner.git
cd AutoVulnScanner
pip install -r requirements.txt
python app.py
